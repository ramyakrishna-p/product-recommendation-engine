# Product Recommendation Engine

**Machine Learning / Software | Python, Pandas, Collaborative Filtering, FP-Growth-style Association Rules**

All data is **SYNTHETIC** — generated by `recommend.py` (seed 21). No real customer data.

## What it does
Builds user/item collaborative filtering via co-occurrence scoring, mines frequent product pairs (FP-Growth-style counting), exposes a `Recommender` class, and evaluates on a hold-out split.

## Run
```bash
pip install -r requirements.txt
python recommend.py
```

## API-style use
`Recommender.recommend(user_id, k=3)` in `recommend.py`. FastAPI wrapper example: create an app, instantiate the recommender on the transactions matrix, and expose `GET /recommend/{user_id}` returning `{"user_id": ..., "recommendations": [...]}` (install `fastapi uvicorn` separately). See `api_example.py`.
